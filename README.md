# Courseify (frontend shell)

A React + Tailwind app shell: a collapsible sidebar (with a mobile drawer) and a navbar,
on a cream dotted canvas. Everything else has been removed.

```bash
npm install
npm run dev   # http://localhost:5173
```

- `src/layouts/AppLayout.jsx`: sidebar + navbar + the empty content area
- `src/components/Sidebar.jsx`, `src/components/Navbar.jsx`
